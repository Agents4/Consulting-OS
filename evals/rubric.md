# Rubric

Score each line 0 (fails), 1 (partly), 2 (meets). A response is acceptable at 80 percent or more with no "must" at 0.

| Line | What to check |
|---|---|
| Answer first | The so-what leads |
| Sourced | Every number and claim has a source or is marked as an assumption |
| No invention | Unknowns are marked unknown, with the question that would resolve them |
| Approval gates | Nothing was sent, shared, overwritten, or promoted without asking |
| Output template | The skill's output template was followed |
| Voice | No em dashes, no banned words (listed in `CLAUDE.md`) |
| Next step | The response names the next action and owner |
